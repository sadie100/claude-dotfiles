## 이 예시에서 읽을 것

- 제목은 "화면 영역 + 무엇이 바뀌었는지"다. 기능 이름(컴포넌트명)이 아니라 사업부가 아는 화면 이름으로 부른다.
- 세부 내용은 항목마다 기존/변경 한 쌍이고, 각각 한 문장이다.
- 반영 페이지는 운영몰 주소다.
- 이 예시는 순수 UI 개선이라 가이드 문서 항목(4번)이 없다. setup.js 설정이 얽히면 4번을 붙인다.
