# 나쁜 예와 고친 예

2026-09-14 한끼통살 플러그인 재조사 문서에서 나온 문장들이다. "고친 예"는 사용자가 직접 고친 문장이므로 이 문체가 기준이다.

## 첫머리 문단

**나쁜 예**

> 2026-07-22 분석(노션 「[한끼통살] 외부 플러그인 분석」(TASK-2380) 및 그 하위 상세 분석 문서)의 후속. 7월엔 스킨 코드 + 관리자 마이앱 목록만 대조해서 관리자가 직접 주입하는 스크립트 레이어를 놓쳤다(뷰저블을 "미사용 잔재"로 오판 → 커머스팀 피드백). 이번엔 라이브 렌더를 기준으로 다시 잰다.

**고친 예**

> 2026-07-22 분석(링크)의 후속 분석입니다. 7월엔 스킨 코드 및 관리자 마이앱 목록만 대조해서, 관리자가 직접 주입하는 스크립트 레이어가 분석 대상에서 제외되었습니다. 따라서 이번엔 라이브 렌더를 기준으로 재측정하였고, 아래는 그 결과입니다.

**적용 규칙**: 체언 종결("~의 후속.") 금지, 괄호 안 긴 설명 제거, 화살표(→)를 접속어로, 마지막 문장에서 다음에 올 내용을 예고.

## 표 셀

표 셀은 메모체를 허용하되 "판정어(부연)" 순서로 쓰고, 화살표·대시·굵게를 쓰지 않는다. 식별자는 인라인 코드로 남긴다.

| 나쁜 예 | 고친 예 |
|---|---|
| **미실측** — 공유 크롬의 관리자 세션 만료(로그인 필요) | 미실측(공유 크롬의 관리자 세션 만료) |
| **사라짐 → 남길 것은 이식** | 사라짐(남길 것은 이식) |
| `gtm.js` 404 → 아무것도 안 함. 정리 대상 | `gtm.js` 404 (아무것도 안 함, 정리 대상) |
| **7월 "미사용" 판정 정정**. 스킨 `list1.html`의 `b180709e103609u436`은 죽은 코드 | 7월 "미사용" 판정 정정(스킨 `list1.html`의 `b180709e103609u436`은 죽은 코드) |
